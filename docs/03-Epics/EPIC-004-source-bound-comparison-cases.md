# EPIC-004 — Quellengebundene Vergleichsfälle

Status: planned · Milestone: [MILE-002-A](../02-Milestones/MILE-002-grammar-sampling.md)

## Ergebnis

Die nächste Analyse kann neu erstellte synthetische Fälle mit expliziten Quellen, Modell-/Profilversionen und vorab fixierten Erwartungen nachvollziehbar prüfen. Der bestehende historische Herkunftsvertrag bleibt erhalten.

## Akzeptanz

- Alle fünf Ansätze haben eine abgegrenzte Referenz- und Regelbasis; normative Aussagen und eigene Annahmen bleiben unterscheidbar.
- Neue Fälle besitzen eigenständige Herkunft und Hashbindung, ohne sich als historische Proben auszugeben.
- Bestehende Fälle/Fehlergrenzen bleiben kompatibel; eine kleine versionierte Erweiterung reicht.
- Kein allgemeines Adapterframework, keine neue fachliche Cube-Semantik.
