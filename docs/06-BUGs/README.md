# BUGs

Hier liegen reproduzierbare Abweichungen zwischen zugesagtem und beobachtetem Verhalten. Eine bekannte Einschränkung, ein fehlendes Feature oder eine Forschungshypothese ist nicht automatisch ein Bug.

Noch keine Bug-Tickets angelegt. Die Discovery-Abweichung wird zunächst im [Vorbereitungsentwurf](../../openspec/changes/archive/2026-11-01-prepare-grammar-comparison/design.md) eingegrenzt.

Neue Einträge: `BUG-NNN-kurzname.md`; Erwartung, tatsächliches Ergebnis, minimale Reproduktion, Versionen, Auswirkung und verwandter Change. [Vorlage](../99-templates/BUG.md).
