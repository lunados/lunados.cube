# Architekturentscheidungen

Noch keine Architekturentscheidung durch dieses Setup akzeptiert. Neue ADRs benennen Problem, Optionen, Entscheidung, Konsequenzen und Status. Ein dokumentierter Vorschlag bleibt `proposed`, bis die Entscheidung tatsächlich getroffen ist.
