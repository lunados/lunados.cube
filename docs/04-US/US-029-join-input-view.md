# US-029 — Join je Eingang sehen

Status: planned · Epic: [EPIC-009](../03-Epics/EPIC-009-instance-view.md) · Mile: [MILE-009-A, -B, -C](../02-Milestones/MILE-009-instance-view.md)

Als Prozessverantwortlicher möchte ich an einem parallelen Join jeden erwarteten Eingang mit seinem Status sehen, damit ich „wartet noch“ von „ohne alle Eingänge weitergelaufen“ unterscheiden kann.

## Akzeptanz

- Eingangsliste mit Status je Eingang, `join_waiting` und `join_incomplete` getrennt benannt, fehlender Eingang namentlich.
- Modellfluss getrennt von der Spur; ein Schritt gilt nur mit Token als gestartet.
- Die in den verlinkten Tasks benannten Abschlusskriterien sind erfüllt oder konkret offen ausgewiesen; offene Pflichtkriterien verhindern den Story-Abschluss.
