# US-028 — Instanz und genommenen Pfad sehen

Status: done · Epic: [EPIC-009](../03-Epics/EPIC-009-instance-view.md) · Mile: [MILE-009-A, -B, -C](../02-Milestones/MILE-009-instance-view.md)
