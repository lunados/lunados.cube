# US-002 — Lokale Fähigkeiten zuverlässig erkennen

Status: done · Epic: [EPIC-002](../03-Epics/EPIC-002-local-capability-discovery.md) · Milestone: [MILE-001](../02-Milestones/MILE-001-analysis-readiness.md)
