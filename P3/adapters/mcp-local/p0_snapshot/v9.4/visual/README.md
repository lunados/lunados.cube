# AIAEAO Visual Grammar – Cube v9.4

This is a **projection / visual-symbol index**, not an executable permission language.
`symbols.json` reproduces the 129 Annex-J anchors, 4 historical alias IDs, and
source-scoped review notes. Glyphs have one Unicode codepoint each. Never derive
identity, proof, Authority or stable hashes from display glyphs or their fonts.

The source Morphology states that 26 mathematical operators are reserved **in a
separate palette**, but does not reproduce that complete palette in Annex J.
This P0 therefore intentionally does not fabricate that registry. Display-only
mathematical overlap warnings are retained as originally documented.

Visual projections are lossy unless explicit source/projection bindings prove
otherwise. No renderer or SVG font fallback is shipped at P0.
