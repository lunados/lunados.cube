Cube Visual Printer · VP-06

Vier deterministische Golden-SVGs aus deklarierten, nicht verifizierten Fixtures. Kein Server, keine JavaScript-Anwendung, keine neuen Semantiken.

Zu jedem SVG gehören im Ordner examples/ der VP-03-Bundle, der VP-04-Druckauftrag und der VP-06-Report. Fehldeklarationen werden vom CLI abgelehnt. Glyphendarstellung kann je nach System variieren.
