# Examples: mappings and syntax-shape fixtures

`migration.json` and `metaphysics.json` are hypothetical foreign-world model
mappings; no actual event, external data or truth is attested.

Their `.acg` / `.ast.json` companions show the **proposed structural shape**
of a qualified expression and a corresponding JSON AST. The example-specific
`example:*` strings are fictitious addresses; no real resolver profile exists.
A relationship expression is not proof that the relationship holds, that a
REL-01 contract has been adopted, or that it may cause an external effect.
`related` intentionally does **not** claim formal logical contradiction.
